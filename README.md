# Divider

A focused Python exercise implementing division functionality in `division_function.py`.

## Requirements
- Python 3.8 or later

## Run
```bash
git clone https://github.com/dperry713/divider.git
cd divider
python division_function.py
```

The module can also be imported by other Python code if it exposes reusable functions.

## Project structure
- `division_function.py` — division-related function implementation.

## Development
Define behavior for zero divisors and invalid inputs. Test positive and negative values, integer and floating-point results, and error handling.
